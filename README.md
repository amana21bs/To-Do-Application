# Listify - Android To-do Application

Listify is a modern Android To-do List application developed using Java in Android Studio.

## Features
- Splash Screen
- User Login & Signup
- Add Tasks
- Edit Tasks
- Delete Tasks
- User Profile Management
- Material Design 3 UI

## Technologies Used
- Java
- Android Studio
- XML
- RecyclerView
- SharedPreferences

## UI Design
The application UI was designed based on Material Design 3 principles using Figma.

## Developer
Developed for the Mobile Application Development module assignment.
